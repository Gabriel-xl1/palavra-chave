# Palavra-Chave

Jogo de família para adivinhar senhas com dicas de uma palavra só, adaptado das regras do jogo de tabuleiro *Mega Senha Especial*.

- Funciona no navegador do celular e pode ser instalado na tela inicial ("Adicionar à tela inicial").
- O modo 1 celular funciona sem internet.
- Para acrescentar senhas, edite `js/palavras.js`.
